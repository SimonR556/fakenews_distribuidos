# Resultados experimentais

Ainda não há benchmarks das versões do grupo.

Guardar aqui dados brutos, tabelas e gráficos gerados pelo integrante 4. Cada conjunto deve identificar commit, parâmetros, semente, repetições, gerações efetivas, contagens finais, trabalhadores, hosts e configuração do ambiente.

Registrar a política de cronometragem e usar as mesmas entradas nas versões comparadas. Sugestão de colunas: `versao`, `linhas`, `colunas`, `geracoes_maximas`, `geracoes_executadas`, `percentual`, `semente`, `limiar`, `trabalhadores`, `hosts`, `repeticao`, `tempo_s`, `ignorantes`, `espalhadores`, `inativos`, `commit`.

Calcular speedup e eficiência a partir de tempos comparáveis e relatar dispersão, além de uma medida central. Não usar tempos de funções simuladas como resultados finais.
